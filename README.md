# RoadTrip Music
A web app that generates Spotify playlists based on your driving route.

# Features
Route planning with turn-by-turn map.
Auto-generated playlists based on regions along the route.
Manual track search/playlist creation.
Light/dark mode.
Mobile responsive.

# Services Used
Spotify Web API
OpenRouteService API
Leaflet.js/OpenStreetMap

# How to Run
Navigate to website.
Navigate to "Create Playlist" page, enter starting location & destination.
Enter title and optional description, click "generate songs" button.
Enjoy your personalized playlist.
